Local AI (recommended)

  1. Install Ollama from ollama.com on the same machine as this server.
  2. Run ollama pull qwen2.5-coder:7b in a terminal.
  3. Set OLLAMA_MODEL=qwen2.5-coder:7b in .env, then restart the server.

Remote AI (optional)

Set REMOTE_AI_BASE_URL, REMOTE_AI_API_KEY, and REMOTE_AI_MODEL in the server's .env. Use a trusted OpenAI-compatible provider. API keys stay on the server.

For access outside your own computer, put this app behind HTTPS and preferably a VPN or identity-aware proxy. Do not expose port 3000 directly to the public internet. Configure a strong unique password and session secret.

Security note: this is a self-hostable starter, not a security-audited production service. Keep backups, update dependencies, and review AI-generated code before running it.
